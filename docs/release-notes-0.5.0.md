# Fri 0.5.0

- Ivory, charcoal and marsala surfaces. The native workspace stays glass; cards, buttons and dialogs are opaque.
- Desktop widgets reveal more content as you resize them. Type stays the same size. Larger layouts place the clock/date beside Up next, with progress, integration tiles and later plans below. Empty slots offer +.
- Eight short website stories show what Fri does through headlines, motion diagrams and the existing desktop walkthrough. Videos autoplay muted when visible.
- English-only Electron language resources and maximum installer compression reduce the Windows footprint without removing app features.
- Android development starts in mobile/: Expo/React Native, a shared Room database, native widget configuration, Glance and WorkManager. Android is a local alpha, not a production/store release; see its separate verification document.

Windows upgrades replace old application files while preserving calendar/settings. The installer is unsigned. Premium remains 50,000 VND/month, coming soon; payments and account signup are unavailable.
