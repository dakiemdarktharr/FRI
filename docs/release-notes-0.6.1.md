# FRI 0.6.1 · Bring your plans

- Import timetable images and authenticated calendar pages with optional OpenAI extraction. Confirm missing details through cards before adding appointments.
- Keep fixed classes in place; schedule assignment work in free time before the real deadline. Review overlaps and insufficient capacity explicitly.
- Skip past appointments, avoid identical reimports, and preserve source details when editing an imported appointment.
- Parse recurring, zoned, all-day and overnight ICS events locally.
- Remember source sign-ins in encrypted local vaults, with per-source disconnect controls. No passwords or cookies are sent to the model.

The Windows installer retains the stable app identity and encrypted calendar profile. It is unsigned. Provider sessions can expire; AI reading incurs the user's OpenAI API charges. The release is not a claim of universal website access or complete Android/Apple feature parity. See [setup, behavior and limits](smart-import.md) and [privacy](privacy.md).
